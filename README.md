# Microsoft Entra ID — Identity & Access Management Lab
Status: In Progress — planned demonstration, to be built and tested.
## Objective
Demonstrate secure employee identity administration using Microsoft Entra ID.
### Skills Learned
- Microsoft Entra ID administration
- Identity lifecycle management
- Multi-Factor Authentication and Conditional Access
- Role-Based Access Control and least privilege
### Tools Used
- Microsoft Entra ID
- Microsoft 365 Admin Center
- Microsoft Authenticator
## Steps
1. Create test employee accounts and security groups
2. Assign roles following least-privilege principles
3. Configure and test MFA
4. Evaluate Conditional Access policies
5. Document successful and blocked sign-in scenarios
Evidence to be added: Configuration screenshots, test cases, and security explanations.
